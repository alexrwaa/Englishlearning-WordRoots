## 三个新单元

- **C5 语音学**（week23，7 课，11/11）：气流与受阻方式、发音部位、清浊、送气、
  元音描写、schwa。每一节都落回构词——清浊 → 前缀同化（`in-`→`im-/il-/ir-`、`ad-`→`ac-/af-/ag-`），
  schwa → 非重读元音弱化与 `cavalry`/`chivalry` 双式，送气不辨义 → `ph`/`th` 的拼写来源。
- **C8 用法与变异**（week24–26，18 课，36/36）：标准语的三种来源、印刷术与互联网两次定形、
  韦伯斯特拼写改革、规定主义与交际效果。落点是构词与拼写史（`debt` 的拉丁化补写、`-our/-or`）。
- **C10 印欧语源**（week27–30，18 课，35/35）：格里姆定律、构拟与星号约定、喉音假说、
  祖语屈折、语言考古、拉丁与希腊的招牌音变。重构形式一律加星号并标注「构拟，非文献实证」。

## 内容修正

- C4 的 `factory` 拆解由 `fac + ory` 改为 `fact + -ory`：前者拼不出 `factory`，
  词根 `fact-` 才是 `fac` 的完成分词词干。测试（`answer.test.ts` 的「每个 wordSum 可解」）抓到了这一条。
- 同化表述统一按语音条件：`in-` 只在 `p/b/m` 前变 `im-`，`dis-/ob-` 才在 `f` 前变 `dif-/of-`。

## 打包与门禁

- 周课时下限从 5 放宽到 **4**：单元允许 5+4 这类不等分周，`week29/30` 各 4 课。
  索引仍逐周记录真实课时与连续日号，截断照样能发现。
- 新增 `scripts/check-ps1.ps1` 并在 CI 运行：0.5.0 的打包失败源于一个未闭合的 here-string，
  整段脚本无法解析，日志只有 "exit code 1"。现在解析失败会直接给出文件与行号。
- 发布门禁在 v0.5.0 起会驱动 **C9（w13d1）与 C11（w15d1）** 真实答题，本版沿用。
