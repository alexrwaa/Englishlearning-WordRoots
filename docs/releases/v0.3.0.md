# WordRoots 0.3.0

这一版把「先排 12 周课，再往里塞词素」反过来：**先把教材拆成清单，再让词库和课程去对齐清单。**
最重要的产出不是新页面，而是两个可复核的数字来源——教材清单与覆盖率审计。

## 教材来源与边界（先说清楚）

| 编号 | 教材 | 状态 | 用法 |
| --- | --- | --- | --- |
| S1 | *English Vocabulary Elements* 3rd ed. (OUP) | **全文已解析** | 主教材：章节结构、知识点、构词成分清单 |
| S2 | *Essentials of Linguistics* 2nd ed. (CC BY-NC-SA) | **来源未获取** | 仅按公开的语言学通识写概念对比，不声称「覆盖该教材」 |
| S3 | WordWorks SWI 资源集 | **来源未获取** | 采用公开描述的 SWI 探究流程（观察→假设→检验→修正），未复制讲义 |
| S4 | *New Word-Analysis* (1879, 公有领域) | **来源未获取** | 与 S1 重叠的古典词根由 S1 覆盖，19 世纪词源结论需另行核验 |

S1 的 EPUB 只在本机解析：章节正文、附录扫描表（`Element | Gloss | Chapter | Source`）逐页转录为
事实数据（成分形式、释义、章节号、语源），**仓库里没有教材原文、扫描页或逐句改写**。
解析中间产物在 `analysis/`（已 gitignore），可发布的只有派生事实与原创中文讲解。

## 新增：教材清单与覆盖率审计

- `src/content/textbook/sources.json`：四组来源的取得状态、许可与用途边界。
- `src/content/textbook/s1-elements.json`：从附录逐页转录的 **550** 个构词成分（形式、变体、释义、章节、语源）。
- `src/content/textbook/s1-chapters.json`：**11 章 / 116 节 / 283 个知识点**（类型、中文摘要、术语、例词、适用阶段）。
- `src/content/textbook/kp-map.json`：知识点与课时的映射及理由（谁映射到谁、为什么、哪些没映射）。
- `docs/TEXTBOOK_COVERAGE.md` + `docs/coverage.json`：由 `npx tsx scripts/coverage.ts` 现算，
  每个成分标出「入库 / 讲解 / 练习 / 核验」，每个知识点标出对应课时。

## 词库扩容

- 词素：**206 → 667**（新增 438 条来自教材附录，440 条含中文释义；
  拉丁 392 / 希腊 217 / 古英语 24 / 法语 20）。
- 词条：**473 → 673**（新增 200 条，其中 258 条带词源、197 条标记已核验）。
- 新增 `scripts/lexicon-tool.ts`：批次合并、去重、**允许修正已存在词条的切分**
  （旧逻辑下 `expect` 被误切为 `exs+pect` 这类错误无法被后续批次修正）、一致性检查。
- 新增 `scripts/build-elements.ts` / `scripts/build-textbook.ts`：把转录表格与知识点片段装配成可审计清单；
  被截断的 JSON 片段按括号深度自动补全而不是整份丢弃；同形异源（`plac` 平 / `plac` 取悦）按
  `形式+语源+释义` 去重，不会被静默合并。

## 构词实验室重构

- 新增派生引擎 `src/lib/derive.ts`：按真实顺序应用并**记录**拼写规则
  （去 e、y→i、双写、同化、`-t/-s→-tion`），支持多层派生链。
- 矩阵升级：多层词基 + 三态单元格——`verified`（词库存在）/ `rule-blocked`（违反规则，给原因）/
  `unknown`（**未收录**，不再等于「英语里没有」）。
- 新增 `#/family/:id` 词族页：按前缀派生/后缀派生/复合分组，派生层次树可展开，
  同源与「仅拼写相似」分开标注，证据不足直接写「未核验」。
- 新增 `#/explore` 自由探索页：输入任意词 → 切分、成分释义、词族入口，未收录时给出三种可能解释。

## 课程体系

`docs/COURSE_PLAN.md` 把教材章节映射到 8 个阶段（基础 / 拼写与形态 / 拉丁 / 希腊 / 词义演变 /
用法与变体 / 历史与借词 / 科技与综合），现有 12 周明确定位为 **S1 基础**，不再假装是全部。
每日 25 分钟的五段结构（新知识 / 词族观察 / 互动分析 / 陌生词推理 / FSRS）写进同一份文档。

## 内容勘误

- 修正一条错误规则：`-ss-`（miss-/cess-/sess-）不是「t+t→ss」的共时拼写规则，而是拉丁过去分词词干；
  相关知识点改写为词干变体 + 历史音变，与课程 w05d6 的讲法对齐。
- 补上缺失的知识点「屈折 vs 派生」——课程 w01d4 一直在教它，但教材清单里没有对应条目。

## 质量与回归

- 单元测试 95 → **128**（新增派生引擎 33 条）。
- `tsc` / `eslint` / `vite build` 全绿；内容校验通过（12 周 / 84 课 / 559 题 / 667 词素 / 673 词条）。
- 0.2.0 的启动与代理修复全部保留：`custom-protocol` 生产构建、WebView2 进程级直连、
  启动诊断文件、`--diagnose`、8 场景冒烟门禁。
