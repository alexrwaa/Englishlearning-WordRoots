# WordRoots 0.5.0

本版把教材 C4、C6、C7 三章从「有知识点、没有课」变成「有课、有练习、能验证」，
并把「C9/C11 在正式安装包里真的能答题」写进发布门禁。
上一版见 [`releases/v0.4.1.md`](releases/v0.4.1.md)。

## 覆盖率变化

| 指标 | 0.4.1 | 0.5.0 |
| --- | --- | --- |
| 课程规模 | 16 周 / 110 课 | **22 周 / 148 课** |
| 知识点被课程引用 | 113 / 283（40%） | **159 / 283（56%）** |
| L5 有讲解 | 30% | **31%** |
| L6 有练习 | 11% | **13%** |
| C4 异形与交替 | — | **19/19** |
| C6 音变规则 | — | **23/23** |
| C7 词义变化 | — | **31/31** |

三章合计新增 38 课、190 张卡、228 道题。每日时长仍按 24–28 分钟设计，
每课都有 `explain`，每课至少一道「陌生词迁移」题。

## 三个新单元

- **C4 异形与交替**（week17–18，13 课）：异形的两大来源、元音弱化、异干互补、
  词素融合、鼻音中缀、`e/o/零` 交替、拉丁与法语双式词、希腊与拉丁同源双式词。
- **C6 音变规则**（week19–20，13 课）：按拉丁音值应用规则、清浊与流音同化、
  `s` 删除与辅音丛简化、插入音、元音间 `s→r`、元音着色、数词素（含 `-illion` 与 SI 前缀）。
- **C7 词义变化**（week21–22，12 课）：语义变化的四类动因、误解与重新解释、
  省略导致的义项转移、`literally` 的语义磨损、委婉语与贬化的循环、变化作用于整词而非语素。

三章的选题边界都写进了课时说明：C4 讲「形式为什么变」，C6 讲「变的规则」，
C7 讲「意思为什么变」，与已完成的 C9（拉丁系统）、C11（借词与音变）不重叠。

## 发布门禁新增：教材单元必须能答题

自检过去固定跑 `w01d1`，只能证明「首页那一课能答」。现在：

- Rust `app_info` 增加 `selftest_lesson`（环境变量 `WORDROOTS_SELFTEST_LESSON`）；
- 前端自检按该 id 打开 `#/session/<id>`，非法 id 回退 `w01d1`；
- 冒烟脚本新增两个场景：**C9（w13d1）** 与 **C11（w15d1）**，断言可进入、可作答、
  尝试数增长、数据库非空。

也就是说，下一次 tag 构建会自动证明：教材单元在正式安装包里可进入、可答题、可落库。

## 打包与索引
