# WordRoots 0.3.1

本版补上 0.3.0 发布时**没赶进标签的构词实验室精修**，并修正引擎里的一个真实判定错误。
教材审计、词库扩容、课程体系文档与 0.3.0 完全一致（见 [`releases/v0.3.0.md`](releases/v0.3.0.md)）。

## 为什么会有 0.3.1

0.3.0 的 `v0.3.0` 标签指向的提交里，实验室的重构主体已经存在（派生引擎、三态矩阵、词族页、探索页），
但最后一轮精修（同形词拆分、多层阶梯、吸顶表头、搜索分组、词族树只显示可派生关系）当时还在工作区，
没有进标签。与其覆盖已发布的包（本项目禁止同名覆盖），不如按语义化版本发一个补丁版。

## 实验室精修

- **同形异源不再被合并**：`spect`（看）与 `spic`（看）是同一词族变体，而 `plac`（平，希腊）与
  `plac`（取悦，拉丁）是不同词源，图谱与矩阵都不再混为一谈。
- **多层阶梯**：矩阵行是逐级派生的词基（help → helpful → unhelpful → unhelpfulness），
  不再是平铺的前缀/词基/后缀三段。
- **吸顶表头 + 三态图例**：长矩阵滚动时表头固定，`verified` / `rule-blocked` / `unknown` 三态有图例，
  避免把「未收录」误读成「不存在」。
- **搜索与分组**：按词族、词性、后缀过滤，结果按词族分组；大词库（667 词素）下仍可定位。
- **词族树只显示可派生的关系**：拼写相近但没有派生关系的词放进「疑似同源/未核验」，不连接成树。
- **探索页给出完整链路**：切分 → 成分释义 → 词族入口 → 未收录时的三种可能解释与相近词建议。

## 引擎修正

`buildWord` 对 `unhelpfulness` 之类多层词曾按「最后一步」判定，导致中间层拼写被跳过；
现按每一步的词基重新计算，并记录规则（去 e / y→i / 双写 / 同化 / `-t/-s→-tion`）。
派生引擎测试增加到 **34 条**，加上矩阵模型测试，前端单元测试合计 **136 条**。

## 验证

- `tsc` / `eslint` / `vite build` 全绿；前端单元测试 8 文件 / 136 通过。
- 课程内容校验通过；教材覆盖率数字与 0.3.0 相同（550 成分 100% 入库、87 个 16% 已讲解、
  283 知识点 71 个 25% 已映射），由 `npx tsx scripts/coverage.ts` 现算。
- Windows 便携包仍走 8 场景冒烟门禁（死代理 / 死 SOCKS5 / 注册表系统代理 / 死 PAC /
  中文空格路径 / 换路径迁移 / `--diagnose` / 无代理基线），失败则不发布。

## 已知缺口

与 0.3.0 相同，未在本版变化：教学覆盖 16% / 25%、例词入词库 48%、S2/S3/S4 来源未获取、
前端包体约 1.2 MB。
