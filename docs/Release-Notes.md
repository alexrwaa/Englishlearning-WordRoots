# WordRoots 0.4.0

本版处理的是**内容与数据的地基**，不是界面：教材成分第一次有了稳定的语言本身份，
四份教材全部落地，音节覆盖率从「四格」升级为七级可审计的指标，冷启动不再卡在解析 1.2 MB JSON 上。
上一版说明见 [`releases/v0.3.1.md`](releases/v0.3.1.md)。

## 1. 词素身份（本版最重要）

旧实现把**拼写**当身份，于是同形异源被合并：`plac` 只剩拉丁「取悦」，希腊「平板」消失；
`in-` 只剩否定，方位义消失；`bi` 只剩「二」，「生命」消失。这类错误不会报错，只会让词族、
矩阵、课程与统计同时指错。

现在：

- **ID 冻结**：已分配的 ID 不再重写，学习者卡片、笔记、收藏不会失效；新条目按 `form + origin` 追加后缀。
- **一对多索引**：`form → [id…]`（`forms.json`），有歧义时**不猜**——`resolve()` 无提示必返回 `ambiguous`。
- **四组回归**：`plac`（取悦/平板）、`in-`（否定/向内）、`bi`（二/生命）、`ver`（真/敬畏）各归其位，
  `placate` 与 `placoid`、`invisible` 与 `inject`、`verify` 与 `revere` 都落到正确词素。
- **词条与卡片带身份**：`WordEntry.partIds`（2315 个词条里 951 个可精确解析）、卡片 `morphemeIds`。

规范见 [`DATA_IDENTITY.md`](DATA_IDENTITY.md)。

## 4. 两个新教学单元（26 课）

- **C9 拉丁系统**（week13–14，14 课）：屈折与派生之分、名词格与复数、拼写复原、
  形容词与动词后缀、现在/完成分词、动形词，20 个知识点全覆盖。
- **C11 音变与借词**（week15–16，12 课）：学术借词与法语中介两条路径、双式词、c→[s] 软化、
  大元音推移、词尾削减、拼写与读音分家（`debt`/`island`/`scissors`），23 个知识点全覆盖。

两单元每题都有 `explain`，且每课至少一道「陌生词迁移」题（考词库未收的词）。

## 5. 词库扩容

- 词素 667 → **787**；词条 673 → **1315**（补的是教材例词与课程引用词，含 25 个屈折形式标记）。
- 同形异源条目互指（`homographs`），全形变体（`allomorphs`）归并。

## 6. 冷启动

前端从「单体 1.17 MB、模块求值期解析全部 JSON」改为按需加载：
主入口 154 kB，词库独立 chunk，浏览器冷启首屏 **321 ms**、FCP **272 ms**、`#/matrix` 挂载 209 ms。
细节与未解部分见 [`PERF.md`](PERF.md)。

## 已知缺口

- **L5/L6 仍低**（30% / 11%）：16 周课程覆盖 C1–C7 与 C9–C11，C8/C10 及部分章节尚未排课。
- **L7 只有 4%**：39 条抽样审校，不是全量；其余成分仍需逐条审校。
- **328 个词条 `unresolved`**：多见于整体借词（`American`）与同形两可（`il-` 既可否定也可向内），
  按规范不猜。
- **同源异形未完全归并**：`cap`/`cept`、`mit`/`miss` 仍是两条记录，共享 `familyId` 但未合成一个词素。
- **词形变体与屈折混放**：部分屈折形式（`alumni`）以 `inflectionOf` 标记，未建独立词素关系表。
- **打包版冷启动数字待复测**：浏览器 321 ms 只证明前端不再是瓶颈。
