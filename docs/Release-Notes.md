# WordRoots 0.10.0

**这一版把"partial"从失败指标变成分类结果，并把词族的证据强度搬到了页面上。**
它还修掉了一个让 50 多个词无法解析的死代码键。上一版见 [`releases/v0.9.1.md`](v0.9.1.md)。

## 一、142 个 partial 逐条分类

`segmentation: partial` 原本混着五种完全不同的情况。现在每一类都有明确处理：

| 类别 | 处理 | 说明 |
| --- | --- | --- |
| 自由词干 | 标记，不造词素 | `agree`、`care` 本来就是独立词 |
| 纯拼写成分 | 标记为 orthographic | 静音 e、连接元音、双写辅音 |
| 缺词素记录 | **补记录** | 如 `-ibil`、`-ual`、`posit`，有语源依据才补 |
| 坏切分 | 改切分或标 `verified:false` | 整体借词硬拆成词素是错，不是"更细" |
| 整体借词 | **不拆** | `credo`、`intercom`、`laptop` 现代英语不再分析 |

**partial 142 → 87**，verified segmentation **1305 → 1360**，quizSafe **989 → 1013**。
剩下的 87 条里有多少"本来就不该 verified"写在 `docs/PARTIAL_CLASSIFICATION.md`，没有为了归零而硬拆。

## 二、死代码键：`px-in-lat-2`

`SENSE_PATTERNS` 里有个键指向 `px-in-lat-2`，而词库里从来没有这个 ID（真实记录是 `px-im` 表"向内"、
`px-in` 表"否定"）。**这个键从未生效过**，导致 `inject`/`inspect`/`include` 这类词只能判"歧义"。

修掉之后：exact **1119 → 1171**，ambiguous **16 → 5**，unresolved **338 → 297**。

新增 `sense-patterns.test.ts`：解析器里每个模式键必须对应真实词素，且不得重复——
一个键写错就静默失效，这种错误不该靠人眼发现。

## 七、本轮查出的真错误

1. `px-in-lat-2` 死键（见上），影响 50+ 个词的解析。
2. `cx-terr` 的释义抄成了 `cx-terr-2`（terrere「使害怕」）——两个同形异源词根写反。
3. `rx-stru` 只写"建造"，Lewis & Short 首义是"层层堆叠、排列"。
4. `cx-leg` 引了教材第 274 页，但附录没有 `leg/lex` 条目。

## 八、仍未完成（明确）

1. **学习统计整合未做**：实际用时、提示次数、重复错误类型仍分散在 attempts 里，没有汇总成
   "个人学习报告"；测评趋势只做了测评页内的最小版本，没进统计页。
2. **族页仍是阅读型**：学习者"自己发现规律"的交互只在 week38 的探究课里，族页没有。
3. **希腊词根无跨来源核验**：`graph`/`phon` 不在 Lewis & Short 覆盖范围，只能标"单一来源"。
4. **没有真人学习效果数据**。
