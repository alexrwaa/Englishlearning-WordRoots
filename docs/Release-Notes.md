# WordRoots 0.7.0

**主教材 283 个知识点全部进入课程，每一课都有现实例词、互动分析、错误解释与陌生词推理。**
上一版见 [`releases/v0.6.0.md`](releases/v0.6.0.md)。

这一版最重要的改动不在课程数量，而在**覆盖率本身不再能靠"挂 ID"虚增**：七级判据全部改成"要证据"。
旧口径下 78 个成分是靠"所在章讲过"推断的，现在这部分被剔除并单独报告。

## 二、新增课程（20 周 / 52 课）

- **C1 词汇规模与结构**（week31–32，9 课）：词汇量的分布、外延与内涵、超长技术词的分段赋义、
  `caput` 的四张面孔（capital / chief / chef / head）。第 4 天用"三条借词路 + 一条本土路"的表
  讲清 `cap/cept/cip` 的关系，并明确它们**不是同一条记录**。
- **C2 英语的历史与亲属**（week33–35，18 课）：印欧谱系与 branch/family 之别、格里姆定律、
  五世纪西日耳曼扩张、古英语屈折残余、伦敦标准语转向、元音大推移。每个知识点都落回英语单词
  （`pater/father`、`tres/three`、`street/strata`、`bishop`）。
- **C3 词缀与构词法**（week36–37，11 课）：五类词缀、语义密度、重音作"超缀"、义不等于和、
  缩拼词的再衍生、拟声与声音象征（明确标为"统计倾向，不是规则"）。
- **词族操练周**（week38–39，14 课）：观察—归纳—验证的循环，切分题、真伪词判定、同源异形辨认、
  三层派生、科研句四步拆读。

## 三、探究型练习（新题型）

新增两种题型，逐题都有解释，且能被 Windows 冒烟测试驱动：

- **`boundary` 手动切分**：单词切成可点击的字母间隔，提交后高亮错切位置，并说明"哪一刀切错了"。
- **`judge` 真词 / 伪构词**：每个干扰项必须给出 `whyNot` 判定依据，判分同时展示理由。

week38 有 4 天以 `boundary` 为主（d2 连续 5 道切分），week38d3 是 3 道 `judge`。
选择题仍在，但不再是唯一的评价方式。

| 词素 | 787 | **796** |

| `unresolved` 词条 | 328 | 336（已分类，见下） |

**同形异源修正（本轮抓到并改掉的真错误）**：`terr`、`sex`、`sal`、`libr`、`par`、`man`、`cur`、`ven`
在库里各只有一条记录，导致 `terrible` 被挂到 terra「土地」、`salary` 挂到 salire「跳」、
`permanent` 挂到 manus「手」、`intravenous` 挂到 venire「来」。现在补了 8 条独立记录
（`cx-terr-2`、`cx-sex-2`、`cx-sal-2`、`cx-libr-2`、`cx-par-2`、`rx-man-2`、`cx-cur-2`、`cx-ven-2`），
并给相关词条写了可核对的语源，让解析器**按语源证据**选中正确的那一条。
`laptop` 被判为现代复合词，不再连到希腊 `top`「地方」。

这些修正是 L4 43% 里"扣掉"的部分——**宁可数字低一点，也不留假关联**。
