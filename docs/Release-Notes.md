# WordRoots 0.11.0

**这一版把"核验"从词条级降到主张级，并把词族页从参考表改成了探究流程。**
学习者不再先看到答案：先观察词形、自己提假设、用新词和反例检验，最后才写 Word Sum。
上一版见 [`releases/v0.10.0.md`](v0.10.0.md)。

## 一、词源核验：按主张分类（P0）

旧口径下一个数字代表整个词条——`root-sense` 通过一次，看起来就像整个英语词族都被核验了。
现在每条证据都标注它支持的**具体主张**，五类分开算：

| 主张 | 有证据 | 单一来源 | 跨来源 |
| --- | --- | --- | --- |
| 古典语词根原始意义 `root-sense` | 18 | 4 | **14** |
| 古典语内部词形变化与派生 `classical-derivation` | 0 | 0 | 0 |
| 从古典语到现代英语的借词路径 `borrowing-path` | 2 | 2 | 0 |
| 现代英语共时构词结构 `modern-structure` | 2 | 2 | 0 |
| 现代英语词义及语义演变 `modern-sense` | 0 | 0 | 0 |

这张表是本轮最重要的产出：**两个词典都收了某个词根，不等于整个英语词族被核验**。
`borrowing-path` 只有 2 条单来源证据，`classical-derivation` 与 `modern-sense` 一条都没有。

每条记录现在都带：来源名与版本、准确词头、定位方式（行号/条目）、抓取日期与时区、原文引文。
OCR 来源额外保存规范化文本（`quote` 原样 + `quoteNormalized`），避免 OCR 错字进入教学正文。

## 二、希腊来源：LSJ 索引（P1）

- 从 **LSJLogeion** 构建了可复用的索引：**110,938 个词头**，脚本 `scripts/build-greek-index.mjs`，
  不再靠网页抓取。
- 核验 6 个成分：`graph`、`phon`、`chron`、`metr`、`logy`、`psych`，全部 `root-sense` 支持。
  其中 `graph`/`phon` 因已有 Wiktionary 记录而成为**跨来源**（新增 2 条）。
- **许可证**：LSJ 文本公有领域，数字转写为 CC BY-SA 4.0；本项目只存短引文 + 指针，不重分发全文，
  并在 `sources.json` 的 `G3` 条目写明义务。
- **查出的语义错误**：
  - `cx-psych` 原释义"心灵" → LSJ 首义是**「气息、生命、灵魂」**，"mind" 是后世经拉丁与基督教哲学才突出的义项。
  - `cx-logy` 原释义"学科" → **λόγος 本义是「言、说、道理、账目」**，LSJ 不把 "study of" 列为该词义项；
    "学科"来自 `-λογία/-logie` 这个派生后缀。两者已分开写。
- **没做到的**：英语借词路径（`borrowing-path`）对希腊成分**一律没有证据**，因此保持未核验。
  查到同形希腊词不等于确认了借词关系。

## 三、词族探究：从阅读到发现（P1，本轮重点）

词族页新增六步探究面板，逐步推进，不预先展示答案：

| 步骤 | 学习者做什么 | 是否自动判分 |
| --- | --- | --- |
| ① 观察 | 只看 6 个词形（无切分、无释义），圈出共有字母串 | 否 |
| ② 发现 | 从一组里挑出"长得像但来历不同"的那个 | **是**（事实题） |
| ③ 假设 | 自己写下词根含义 | **否**（只说"接近/有关/差得远"，从不说"错"） |
| ④ 验证 | 判断新词是否属于这一族，逐条给理由 | **是**（成员与反例都是事实） |
| ⑤ 反例 | 读同形异源词为什么不算 | 否 |
| ⑥ 总结 | 写 Word Sum，多种合法写法都接受 | **是**（接受多解） |

- 进度按词族存在本地，可中途离开再回来。
- 只对事实性答案自动判分；自由文本假设永不判错——程序不知道学习者用的是哪种诚实说法。
- 词库未收录的词标"词库未收"，不当作"不是英语词"。
- **Windows 冒烟新增真实 GUI 流程**：进入探究面板 → 点"发现" → 选词 → 核对 → 下一步 →
  断言进度已落盘。不是只跑单元测试。

## 四、词族成员补全（P1）

171 个档案成员中，可点开词条的比例 **77% → 96%**（131 → 164）。
新增 33 个词条（`symphony`、`chronometer`、`paragraph`、`export`、`import` 等），
7 个判定不收录并写明理由（生僻术语、现代英语已不可分析、语源存疑）。
词库 1473 → **1506**，verified segmentation 1393，partial 仍为 87，quizSafe 1046。

## 六、个人学习报告（P2）

统计页新增报告：**实际作答时长**（按每题 `durationMs` 累加，不是课标估算）、各题型正确率、
薄弱概念（错 ≥2 次）、重复出错的题目，以及一键导出 JSON。

报告里固定写明**它不知道的事**：不含阅读卡片时间、没有"点提示"的事件记录、错误类型只能按题型分。
导出文件带免责声明：**分数变化不能归因于课程**。
