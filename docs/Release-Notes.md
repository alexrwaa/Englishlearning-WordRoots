# WordRoots 0.1.0

首个可运行版本：12 周课程框架 + 每日学习流水线 + 构词实验室 + FSRS 复习 + 便携式 Windows 构建。

## 新增

- **每日学习**：25 分钟四阶段流水线（复习 / 学习 / 练习 / 应用），断点续学，漏学自动摊薄。
- **课程系统**：12 周、84 天课程，7 种卡片类型，中文为主、术语中英对照。
- **构词实验室**：Word Matrix 只对真实存在的词给出释义，并展示拼写规则的实际作用步骤。
- **Word Sum**：区分"词素选错"与"拼写规则用错"两类错误。
- **词源词典**：词素拆分、历史来源、同族词；明确区分历史词源与现代构词分析。
- **FSRS-5 复习**：记忆卡与迁移推理卡独立调度，目标保持率可调。
- **统计与知识库**：真实学习记录驱动的统计、薄弱知识、笔记与收藏。
- **便携式存储**：数据库、配置、日志、备份全部位于程序目录，支持整体搬迁与自动迁移备份。

## 交付物

- `WordRoots-Portable-Windows-x64.zip`：解压即用，无需安装。
- `WordRoots-SHA256.txt`：ZIP 校验值。

## 验证状态

- 前端类型检查、ESLint、单元测试（FSRS / 拼写规则 / 判题 / 计划生成）在 CI 中执行。
- 课程 JSON 通过 Schema 校验：答案范围、引用完整性、占位内容检测、时长预算。
- Windows 构建在 GitHub Actions `windows-latest` 完成，并在含空格与中文的路径下做启动冒烟测试
  （检查数据库与日志是否落在程序目录内）。
- 未自动验证：GUI 点击流程、拖拽交互、DPI 缩放、真实 WebView2 渲染差异。

## 已知限制

- 课程词源以现代参考为准，个别传统解释（如 19 世纪教材的词根分类）标注为历史对照。
- 浏览器开发模式使用 localStorage，仅用于开发预览。
