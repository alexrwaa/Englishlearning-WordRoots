# 附录转录质量审计（S1）

主教材的构词成分清单只存在于两张**扫描图表格**里，没有文本版：

- 附录 A1 *Elements to Glosses*，书页 266–283：`Element | Gloss | Chapter | Source`
- 附录 A2 *Glosses to Elements*，书页 284–300：A1 的反查索引

因此清单的可靠性完全取决于逐页转录。本文件记录做了哪些校验、发现了什么、怎么处理。

## 方法

1. **页级完整性**：统计每页转录行数。正常页 31–34 行；明显偏低（<20）说明漏行或页面裁切。
2. **A1 ↔ A2 交叉核对**：A2 是同一批成分的反查表，若某形式只出现在 A2，说明 A1 漏了它。
   形式归一化处理 `~` 变体、逗号并列、括号注释、首尾连字符。
3. **边界逐行核对**：附录首末页（266 / 283）人工比对原图。
4. **字段合法性**：Chapter 列只能是 1–11 及其组合；Source 列只能是 L / G；不含 `?` 占位符。

### 3. 边界核对

- 283 页逐行比对：11 行完全一致（`vin` 至 `zo`）。
- 280/281 页由人工转录，与另一路转录重叠部分一致；重复的来源已去重。

### 4. 字段合法性

- Chapter 列：合法值全部落在 1–11 组合内（存在 `2,6` 与 `2, 6` 两种空格写法，已归一化）。
- Source 列：仅有 `L`、`G`、`L, G`、`G, L` 四种写法，无其他值。
- 占位符 `?`：0 处。

## 结论

清单可以支撑覆盖率审计，但**不能声称"零误差"**：A1 漏了 11 个成分（已按 A2 补回），
A2 本身有 1 处错列。任何后续统计都必须使用补全后的清单，并在报告里保留 `A2:` 溯源标记，
以便人工回查。

清单的**身份**问题不在本文件范围：成分形式相同但语源不同（`plac` 平 / `plac` 取悦）属于
`docs/DATA_IDENTITY.md` 处理的对象。
