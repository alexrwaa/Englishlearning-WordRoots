# 缺口归因与处理（0.9.2）

对 `docs/textbook-audit.json` 里 S1 的 41 条 partial 与 S2 的 3 条 partial 逐条归因。四种归因的定义与团队约定一致：

1. **真的没讲**：正文无实质讲解 → 补正文（必要时同时补题）。
2. **讲了但缺直接练习**：有讲解/例词，没有专门考它的题 → 补**原创练习**。
3. **有练习但审计没识别**：题干/选项/答案里其实考到了，是映射规则的问题 → 改 `scripts/audit-textbook.mjs` 的识别逻辑。
4. **内容或练习有事实错误**：改正并注明原文错在哪。

> 本次 44 条中没有一条被认定为「事实错误」。两处接近的情况（`kp-s1c2s6-1` 的「四次大扩充」、`kp-s1c9s2-2` 的「拉丁词根通常不能独立成词」）本身都是真陈述，问题是**没有覆盖知识点要求的那个框架**，因此按归因 1 补正文，不按归因 4 改写原文。

## 三、审计脚本改了什么

1. **`S1_PRACTICE_ANCHORS`（新）**：25 个知识点 → 练习题 + `must` 正则。只用于 S1 的练习识别；`taught` 门槛、`feedback` 门槛、其余练习的 0.35 覆盖率路径一律未动。
2. **`evidence.practice.how`（新字段）**：`anchor` / `recall`，让每条判定能看出走的是哪条识别路径。
3. **`S1_TEACHING_OVERRIDES`（新）**：4 条知识点的讲解证据改指真正讲解该点的卡。原来 `evidence.teaching` 取「覆盖率最高的相关卡」，这 4 条最高的是邻近概念（例：`kp-s1c1s4-1` 的 c2 讲「被误认的后缀」，真正的讲解在 c5）。只改证据指针，不改判定。
4. **S1 讲解证据的挑选**：在相关卡里优先取「本身有实质正文且带例词」的卡，而不是纯字符命中最高者。
5. **`S2_MATCHERS.selection`**：`/宿主(词性|条件|限制)/` → `/宿主(词性|条件|限制|必须|要求)/`，另加 `/接缀(条件|限制|规则)/`。`w38d3-p4` 的选项原文是「-ness 的宿主必须是形容词或分词」，旧正则不匹配；这是一条真实的识别缺陷，不是放宽门槛。
6. 报告叙述按新结果重写（S1 的 41 条说明、S2 的三条说明）。

## 五、抽查三条

1. **`kp-s1c5s5-3` 三元特征可唯一确定辅音**（归因 2）
   正文 `w23d5-c4`：「给出发声态、部位、方式三个值，一个辅音就被唯一确定……题目说『清、软腭、塞音』，答案只能是 [k]」。新题 `w23d5-p6` 给的正是「清音、双唇、塞音 → [p]」，三个干扰项各错一根轴（[b] 错发声态、[f] 错方式、[m] 错方式）。正文与题目同构，题目不是背定义，而是反用三轴。
2. **`kp-s1c2s6-1` 以三阶段为纲叙述借词史**（归因 1）
   原课只有 `w09d7-c1`「四次大扩充」表，没有教材的三阶段框架。新卡 `w09d7-c6` 写出古英语 / 中古英语 / 现代英语三段与 1066 这个门槛，并说明「四次」只是把中古早期拆成两行；新题 `w09d7-p6` 要求把 sky/egg、government/justice、atmosphere/dictionary 排进三个阶段（选项 1–3 分别把阶段对调或宣布「都属现代英语」）。卡与题互为支撑。
3. **`kp-s1c7s12-1` 判别标准：相似还是相关**（归因 3）
   讲解卡 `w10d3-c3`「两步判断：这是隐喻还是转喻」——先问是否跨域，再问能否改写为「像」。题 `w10d3-p3` 给四句，要求选出「用的是隐喻而不是转喻」的那一句（正确项 `The argument collapsed under scrutiny.`），正是两步判断的执行；旧版审计因题干命中字符不足 0.35 漏记。
