- **没有发现「只挂 ID 不讲课」的空挂**。27 个 pass 样本的解释与练习都能逐条对上，正文不是复述标题而是给了判据与反例。

### 结论

S2 的强项是**构词机制**（复合、派生、截短、混成、逆构、转换、重新分析、类推、异干、变体）——基本每条都有「判据 + 反例 + 练习」三件套，且敢于交代学界分歧（如 w36d1 的 -o- 算间缀还是连接元音、w37d3 的 -bolic 不是真词素）。

缺口集中在**理论框架与形式化工具**（树形图、结构歧义、形态类型学、语法化），以及**只作单点证据出现的术语**（blocking、reduplication、metathesis）——后者讲对了但没有被提升为可迁移的规则、也没有练习。这一类缺口对「读懂 S2 教材」有影响，对「用词根背单词」影响很小——是否需要补，取决于课程定位是「构词素养课」还是「语言学导论课」。

### 3.1 归纳检查

**方法周（第 2、38、39 周）确实要求自己归纳**，最强的是三处：

- w38d1：五个含 cur 的词只给中文义，词根义留白，并要求「核心义必须同时解释五个词」；随后用 cur（关心）/curr（跑）的同形不同源逼学生用同族词而非拼写做判据。
- w38d3：四个伪构词分别对应四类违规，学生必须写出一句可检验的依据；三道 judge 题只问「哪一个是真词」，理由要自己给。
- w38d6：矩阵故意留空格，并要求说明「哪些格子必须空着」（-ness 要形容词宿主等），练习是补格与排除非法格，不是背四个现成词。

**内容周多数是「先给结论再练应用」**，归纳退化为验证：

- w13d6 开篇直接给 caud-（尾）、oss-（骨）、ped-（脚）；
- w05d1 开篇即给 struct = 建造，再列四个前缀方向；
- w14d6 先给完成分词语义与 doct-/act-/sens- 词干，练习只考辨认与迁移。

产出型（wordSum + matrix + boundary + judge）合计 **184/1513 = 12.2%**，其中第 38、39 周占 19 道 wordSum（13.7%）。**SWI 的「写出来」在总量上仍是少数派，靠两个方法周集中承载。**

### 结论

S3 的四步（假设、验证、矩阵、Word Sum）教得到位，且都有可检验的产出物；**唯一缺口是第一步「发现问题」**——所有探究现象都由课程预先挑好（caput 的三种拼写、cur/curr、greenhouse 的重音），学生练的是「处理给定现象」，不是「从真实语料里挑出现象」。S3 的 inquiry cycle 第一步（用真实拼写疑问抓住学生）在课程里没有对应练习。

另有一个统计假象：week38、week39 的 14 节课 `knowledgePoints` 为空，因此 SWI 方法教学完全不进覆盖率账本。看 `docs/coverage.json` 会得出「方法未覆盖」的错误印象。

### 4.3 隔离机制建议

前三条为必做，第四条为可选的防回归措施（与 `s4-history.json` 的 `isolationMechanisms.recommended` 一一对应）。

1. **加统一的四档来源标记，别再靠行文口气。**
   在卡片 JSON 增加 `claimStrength`：`fact` / `mainstream` / `textbook-convention` / `superseded`，渲染成卡片角标（「教材约定」「旧说·已修正」）。现在正文里有 77 处「教材」提及、15 处「主流」、15 处「有争议」、37 处「假说」，且「教材说/教材给/教材把…叫」混用，同一个不确定等级有四五种写法，学生无法一眼分辨。先在 16 条 inventory 上落地，w29d2 的两处标 `textbook-convention` 并链到修正说明。

2. **建 `docs/TEXTBOOK_CLAIMS.md` 作唯一登记处，课程只引用 id。**
   现有 `analysis/s4/obsolete-claims.md` 只覆盖 7 条**成分级**旧说，缺**框架级**旧说（三系列塞音与声门音理论之争、centum/satem、三层借词、三分期、十三分支、形态类型学四分、轮车断代）。每条登记：教材原说法 / 现代分歧 / 保留理由 / 课程处理 / 相关课时。卡片只写一句「见 TEXTBOOK_CLAIMS#wheel-date」，避免同一条免责声明在多节课里各写一遍、措辞漂移。

3. **把「证据强度判断」做成题型。**
   新增一类题：同一结论给两条支持证据，让学生判哪条更强——「英语与拉丁同源」给 (a) pater/father 形近 与 (b) p↔f 成批对应；「祖语有轮」给 (a) 六支同源词 与 (b) 考古发现车轮。可直接复用 w27d4 的证据分级表，把当前只有 5 道、且专用于真词/伪词的 `judge` 题型扩成第二种用法。这类题能把「识别旧说」从阅读体验变成可测能力。

4. **把 obsolete 标记接进构建校验（可选）。**
   写一条回归测试：读 `s4-elements.json` 的 `obsolete:true` 条目，在 `src/content` 中检索「按旧义教学」的模式（如把 -ish 释为 to make、把 n- 列为否定前缀）即失败。当前 7 条均未泄漏，正好作为基线；成本低，能防止以后补内容时把旧说带回来。
